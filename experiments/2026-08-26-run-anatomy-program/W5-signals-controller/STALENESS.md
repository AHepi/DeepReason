## How each verdict is decided

| unit class | what a bound means | the decidable test |
|---|---|---|
| `ratio` / `count` / `tokens` — a LEVEL that persists between emissions | a consumer reading the level in a cycle where it was not re-emitted is reading past the bound | per-cycle COVERAGE: does every cycle with a heartbeat also carry the signal? |
| `event` — an OCCURRENCE | absence in a cycle is information, not staleness; the question is how old the last occurrence was when something believed it | AGE AT CONSUMPTION, where a committed reader exists; `NO-CONSUMER` where none does |
| bound `run` / `permanent` | usable for the life of the run | passes by construction — every read of a logged value happens inside the run that logged it |
